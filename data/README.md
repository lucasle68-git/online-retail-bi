# Data

Raw data is **not committed** to this repository (see `.gitignore`).

- Source: [Online Retail II, UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii)
- Licence: CC BY 4.0
- Content: 1,067,371 transaction lines from a UK-based online retailer, 01/12/2009 to 09/12/2011

To reproduce: download the zip, extract `online_retail_II.xlsx` to `C:\data\`, then run `python/convert_to_csv.py`.
